# 🎓 Student Score Prediction Using Machine Learning

## 📌 Project Overview

Student Score Prediction is a Machine Learning project that predicts a student's expected score based on the number of hours they study.

The project uses Linear Regression to identify the relationship between study hours and student scores.

A Streamlit-based web interface is also included, allowing users to enter their study hours and receive a predicted score.

---

## 🎯 Objectives

- Load and explore the student score dataset
- Perform data cleaning
- Analyze the relationship between study hours and scores
- Visualize the dataset
- Build a Linear Regression model
- Generate student score predictions
- Evaluate the model using MAE, MSE and R² Score
- Develop an interactive Streamlit application
- Publish the complete project on GitHub

## 🤖 Machine Learning Algorithm

### Linear Regression

Linear Regression is used to model the relationship between study hours and student scores.

The model follows the equation:

Score = m × Hours + c

where:

- m = slope
- Hours = number of study hours
- c = intercept
- Score = predicted student score

---

## 📊 Dataset

The dataset contains two main columns:

| Column | Description |
|---|---|
| Hours | Number of hours studied |
| Scores | Student score |

The dataset contains 60 student records.
